¿Qué es AgroFlow CO?

AgroFlow CO es un pipeline de datos que automatiza la obtención, limpieza y análisis de precios mayoristas agrícolas colombianos, publicados por el SIPSA (Sistema de Información de Precios y Abastecimiento del Sector Agropecuario) del DANE.

Cómo funciona:

  1. Un pipeline en Python consulta en vivo el servicio web (SOAP) oficial de SIPSA-DANE.
  2. Los datos crudos se guardan sin modificar, luego se normalizan y validan (fechas, precios).
  3. Se cargan en una base de datos PostgreSQL, evitando duplicados.
  4. Esta página (y también un dashboard en Power BI) consulta esa base en solo lectura para mostrar las gráficas y filtros.

Ningún dato mostrado aquí es inventado o simulado: todo proviene de consultas reales al servicio oficial de DANE.
