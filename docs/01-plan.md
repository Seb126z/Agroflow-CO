# Plan de implementación

1. Inspeccionar el WSDL oficial.
2. Identificar operaciones, parámetros y respuestas.
3. Ejecutar una consulta pequeña.
4. Guardar la respuesta original.
5. Definir el mapeo de campos.
6. Implementar extracción.
7. Normalizar y validar con pandas.
8. Cargar PostgreSQL.
9. Añadir control de duplicados e incrementalidad.
10. Automatizar.
11. Preparar métricas y Looker Studio.

No se debe asumir la operación SOAP ni los nombres definitivos de campos antes del paso 2.
